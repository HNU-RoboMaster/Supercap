# SuperCap 上下位机 CAN 通信协议

总线：1 Mbit/s 经典 CAN、11 位标准 ID、数据帧、DLC 8。字节从 0 编号，所有双字节字段为小端无符号整数，低字节在前。

## 报文列表

| CAN ID | 方向 | 内容 | 发送频率 |
| --- | --- | --- | --- |
| `0x221` | 上位机 → 超电板 | 首次使能命令，字节 0 为 `0x01` | 按需 |
| `0x221` | 上位机 → 超电板 | 控制命令，字节 0 为 `0x02` | 周期发送，板端 500 ms 超时 |
| `0x220` | 超电板 → 上位机 | 使能、状态、功率和储能反馈 | 500 Hz（2 ms） |

## 下行命令帧 `0x221`

| 字节 | 首次使能 `0x01` | 控制 `0x02` |
| --- | --- | --- |
| 0 | 类型 `0x01` | 类型 `0x02` |
| 1 | `Enable`：`1` 首次使能，`0` 无动作 | `RobotAlive`，填 `1` |
| 2 | 保留 | 电池侧功率预算低字节 |
| 3 | 保留 | 电池侧功率预算高字节 |
| 4～7 | 保留 | 保留 |

电池侧功率预算：小端 `uint16_t`，`1 W/LSB`，可编码 `0～65535 W`。

`RobotAlive`：取值 `0～1`，大于 `1` 时整帧拒收。

## 上行反馈帧 `0x220`

| 字节 | 字段 | 定义 |
| --- | --- | --- |
| 0 | 运行开关 `RunEnable` | `0` 未使能，`1` 运行开关已置位 |
| 1 | 状态和标志 | bit 0～3 状态码，bit 4 正常运行，bit 5 允许供能请求，bit 6～7 保留置零 |
| 2～3 | 总功率 `Pbat + Pcap` | 小端 `uint16_t`，`0.01 W/LSB` |
| 4 | 储能百分比 | `uint8_t`，`0～100%` |
| 5～6 | 电池侧功率 `Pbat` | 小端 `uint16_t`，`0.01 W/LSB` |
| 7 | 保留 | `0` |

### 字节 1：状态码与标志

| 状态码（bit 0～3） | 固件状态 | 含义 |
| --- | --- | --- |
| `0x0` | `SC_SELF_TEST` | 自检 |
| `0x1` | `SC_STANDBY` | 待机 |
| `0x2` | `SC_CONNECT_Q3` | 接入 Q3 |
| `0x3` | `SC_SLOW_CHARGE` | 慢充 |
| `0x4` | `SC_CHARGE` | 充电 |
| `0x5` | `SC_DISCHARGE` | 放电 |
| `0x6` | `SC_CROSS_ZERO` | 换向过零 |
| `0x7` | `SC_STOPPING` | 停机过程 |
| `0x8` | `SC_FAULT_LATCHED` | 故障锁定 |
| `0x9` | `SC_START_PWM` | 启动 PWM |
